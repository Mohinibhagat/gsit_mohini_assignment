Task 1: Use of this Keyword 
Create a class named Employee with the following instance variables:
•	int employeeId
•	String employeeName
•	double salary
Requirements:
1.	Create a parameterized constructor that initializes all three instance variables.
2.	Use the this keyword to distinguish instance variables from constructor parameters.
3.	Create a method named displayDetails() to display employee information.
4.	Create two employee objects with different values and display their details.


Code:
package dailyAssignment2;

class Employee
{
	int employeeId;
	String employeeName;
	double salary;
	
	Employee(int employeeId1,String employeeName1,double salary1)
	{
		this.employeeId=employeeId1;
		this.employeeName=employeeName1;
		this.salary=salary1;
		
	}
	void displayDetails()
	{
		System.out.println(employeeId+":"+employeeName+":"+salary);
	}

}

public class EmployeeManagmentSystem {

	public static void main(String[] args) {
           Employee e1=new Employee(102,"Rahul",50000.30);
           e1.displayDetails();
           //System.out.println(e1.employeeId+":"+e1.employeeName+":"+e1.salary);
           Employee e2=new Employee(103,"Sahil",65000.50);
           e2.displayDetails();
          // System.out.println(e2.employeeId+":"+e2.employeeName+":"+e2.salary);

	}

}

Output:

103:Sahil:65000.5
